## 🚀 Projetos em destaque

### 🏭 [Logi-Prime — Sistema de Gestão de Estoque](https://github.com/rickgouveia456-cmd/gerenciador-de-estoque)

> Sistema web completo para gestão de estoque de obras de construção civil, desenvolvido do zero.

- 📦 Controle de almoxarifados, itens, EPIs e ferramentas
- 👷 Gestão de colaboradores e requisições de materiais
- 📊 Relatórios de consumo, alertas de estoque mínimo e previsão de ruptura
- 🔐 Autenticação com 2FA (TOTP), perfis e controle de acesso por cidade/obra
- 🌐 Deploy em produção no Railway com PostgreSQL
- 📱 Suporte a PWA (instalável no celular)
