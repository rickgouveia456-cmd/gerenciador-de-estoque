# 🏗️ Logi-Prime - Sistema de Gestão de Estoque para Obras

## 🎯 **Sobre o Sistema**
Sistema completo de gestão de estoque desenvolvido especificamente para obras e construção civil, com interface moderna e funcionalidades avançadas.

## ✨ **Principais Funcionalidades**

### 👥 **Gestão de Usuários**
- Sistema de perfis: Admin, Almoxarife, Mestre de Obra, Colaborador
- Controle de acesso por almoxarifado
- Acessos temporários e extras

### 📦 **Controle de Estoque**
- Múltiplos almoxarifados
- Controle de estoque mínimo com alertas
- Movimentação em lote
- Status visual (OK, Alerta, Crítico)
- Importação/Exportação Excel

### 📋 **Sistema de Requisições**
- Requisições do mestre de obra
- Fluxo: Pendente → Aprovada → Entregue
- Controle de colaboradores
- Histórico completo

### 📊 **Relatórios Avançados**
- Consumo por período
- Consumo por pessoa
- Alertas de compra
- Exportação para Excel

### 🎨 **Interface Moderna**
- Tema claro com cores laranja
- Design responsivo (mobile-friendly)
- Animações suaves
- Dashboard intuitivo

## 🛠️ **Tecnologias Utilizadas**
- **Backend**: Python Flask
- **Banco**: SQLite (local) / PostgreSQL (produção)
- **Frontend**: Bootstrap 5, HTML5, CSS3, JavaScript
- **Deploy**: Railway, Heroku compatível
